# BUSCAMINAS – Versión Académica

## Descripción

Este proyecto consiste en el desarrollo de un videojuego inspirado en Buscaminas utilizando programación estructurada en C#.

El objetivo del jugador es descubrir todas las casillas seguras del tablero sin seleccionar ninguna mina.

## Características

* Tablero de 5x5.
* Colocación aleatoria de 5 minas.
* Conteo de minas vecinas.
* Detección de victoria y derrota.
* Validación de coordenadas ingresadas por el usuario.
* Uso de arreglos bidimensionales y métodos.

## Tecnologías Utilizadas

* C#
* Visual Studio

## Métodos Implementados

* InicializarTableroVisible()
* ColocarMinas()
* CalcularNumeros()
* ContarMinas()
* MostrarTablero()
* DescubrirCasilla()
* VerificarVictoria()
* MostrarTableroFinal()
